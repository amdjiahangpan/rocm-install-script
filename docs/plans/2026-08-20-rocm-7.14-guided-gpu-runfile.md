# ROCm 7.14 Guided GPU and Runfile Fallback Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Support the official Radeon/Ryzen GFX range through KFD-first detection and guided manual recovery, expose multi-GPU inventory, and add an explicit official Runfile `gfx=all` fallback.

**Architecture:** Extend the existing single Bash installer. Keep architecture-specific APT/PIP/Tarball behavior, add KFD-authoritative handling for unmapped bound PCI devices, preserve GPU count separately from the deduplicated GFX set, and implement Runfile as a distinct method that never activates implicitly.

**Tech Stack:** Bash 5, KFD/PCI sysfs, ROCm 7.14.0 Runfile Installer, fixture-driven shell tests.
