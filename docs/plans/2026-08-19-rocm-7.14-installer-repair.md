# ROCm 7.14 Installer Repair Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make the ROCm 7.14.0 installer recover unsupported-driver hosts safely, choose the reviewed driver/kernel policy, remain idempotent, and complete a verified RX 9060 XT installation on NV20.

**Architecture:** Keep one Bash installer. Separate fact detection, reviewed policy resolution, pure action planning, and mutation. Add a reviewed PCI fallback for pre-KFD recovery, recognize real AMDGPU 31.40 package metadata, and replace unconditional kernel rebooting with an explicit one-shot state machine.

**Tech Stack:** Bash 5, Ubuntu APT/dpkg/DKMS, KFD and PCI sysfs, GRUB, shell fixture tests.
