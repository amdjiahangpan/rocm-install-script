# ROCm 7.14 Multi-GFX Support Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make one ROCm 7.14.0 installer run discover, plan, install, and verify every requested supported AMD GPU architecture on a heterogeneous host while preserving single-GFX behavior.

**Architecture:** Keep one normalized, newline-delimited set of GFX records and one host-wide install plan. Build method-specific artifacts from that set, consume the full collection safely in one installer action, and verify each requested GFX against `rocminfo`; DRM product names remain sorted informational records and never drive artifact selection.

**Tech Stack:** Bash 5, associative and indexed arrays, KFD and DRM sysfs fixtures, shell test scripts sourced with `ROCM_INSTALL_LIBRARY_MODE=1`, `shellcheck`

Add these helpers after `trim_field`:

```bash
normalize_records() {
    local records=${1-} record

    [[ $# -eq 1 && -n "$records" ]] || return 1
    while IFS= read -r record || [[ -n "$record" ]]; do
        [[ -n "$record" && "$record" != *$'\r'* ]] || return 1
        printf '%s\n' "$record"
    done <<< "$records" | LC_ALL=C sort -u
}

normalize_gfxes() {
    local records=${1-} normalized gfx

    normalized=$(normalize_records "$records") || return 1
    while IFS= read -r gfx; do
        validate_artifact_gfx "$gfx" || return 1
    done <<< "$normalized"
    printf '%s\n' "$normalized"
}

records_to_csv() {
    local records=${1-} normalized record csv=''

    normalized=$(normalize_records "$records") || return 1
    while IFS= read -r record; do
        csv+="${csv:+,}${record}"
    done <<< "$normalized"
    printf '%s\n' "$csv"
}
```

The helpers accept exactly one nonempty newline-delimited value. They reject blank or carriage-return records, sort with `LC_ALL=C`, deduplicate exact lines, and never use shell word splitting. `normalize_gfxes` additionally validates every record against `ROCM_714_ARTIFACT_RECORDS`, so one unsupported value rejects the entire set.

```bash
detect_gpu_architectures() {
    local root=${1:-} properties_file line cpu_cores='' gfx_target_version='' gfx records=''

    [[ $# -eq 1 && -d "$root" ]] || return 1
    for properties_file in "$root"/*/properties; do
        [[ -r "$properties_file" ]] || continue
        cpu_cores=''
        gfx_target_version=''
        while IFS= read -r line || [[ -n "$line" ]]; do
            case "$line" in
                cpu_cores_count\ *) cpu_cores=${line#cpu_cores_count } ;;
                gfx_target_version\ *) gfx_target_version=${line#gfx_target_version } ;;
            esac
        done < "$properties_file"
        [[ "$cpu_cores" == 0 && -n "$gfx_target_version" && "$gfx_target_version" != 0 ]] || continue
        gfx=$(kfd_gfx_target "$gfx_target_version") || return 1
        records+="${records:+$'\n'}${gfx}"
    done
    normalize_records "$records"
}
```

- [ ] **Step 4: Implement `resolve_plan_artifacts`**

Replace scalar `resolve_plan_artifact` with `resolve_plan_artifacts METHOD GFX_RECORDS`:

```bash
resolve_plan_artifacts() {
    local method=${1:-} gfxes=${2-} normalized gfx record extras='' artifacts='' count=0

    [[ $# -eq 2 ]] || return 1
    normalized=$(normalize_gfxes "$gfxes") || return 1
    while IFS= read -r gfx; do
        count=$((count + 1))
        case "$method" in
            apt)
                record=$(resolve_package_name full "$gfx") || return 1
                artifacts+="${artifacts:+$'\n'}${record}"
                ;;
            pip)
                record=${ROCM_714_ARTIFACT_RECORDS[$gfx]}
                IFS='|' read -r _ record _ <<< "$record"
                extras+=",${record}"
                ;;
            tarball) ;;
            *) return 1 ;;
        esac
    done <<< "$normalized"
    case "$method" in
        apt) printf '%s\n' "$artifacts" ;;
        pip) printf 'rocm[libraries%s]==%s\n' "$extras" "$ROCM_VERSION" ;;
        tarball)
            if ((count == 1)); then
                resolve_tarball_artifact "$normalized"
            else
                printf '%s\n' "$ROCM_MULTIARCH_TARBALL_ARTIFACT"
            fi
            ;;
    esac
}
```

The normalized GFX order makes APT packages and pip extras deterministic. For `gfx1151` plus `gfx1201`, the pip output must be exactly `rocm[libraries,device-gfx1151,device-gfx1201]==7.14.0`. Tarball mode selects `therock-dist-linux-multiarch-7.14.0.tar.gz` only for two or more supported records. It never overlays tarballs and never treats the full artifact as an unsupported-GFX fallback.
